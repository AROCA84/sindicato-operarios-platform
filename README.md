# SINDICATO DE OPERARIOS

Plataforma de formación online para operarios y trabajadores industriales.

## 🎯 OBJETIVO

Crear una plataforma moderna, profesional y responsive, especialmente optimizada para móvil, donde los usuarios puedan:
- Registrarse gratis
- Estudiar cursos gratis
- Realizar tests gratis
- Consultar resultados inmediatamente
- **Solo pagar al final** si quieren obtener y descargar su certificado (4,99 €)

### Mensaje principal

> **ESTUDIAR Y HACER EL TEST ES GRATIS. SOLO PAGAS AL FINAL SI QUIERES OBTENER TU CERTIFICADO.**

## 🚀 Flujo del alumno

1. El usuario entra en la web
2. Se registra gratuitamente
3. Accede a cursos y temarios
4. Estudia gratuitamente
5. Realiza el test gratuitamente
6. Ve su resultado inmediatamente
7. Si aprueba, se le ofrece obtener el certificado por 4,99 €
8. Realiza el pago
9. Descarga su certificado profesional
